# TENKIプロジェクトのご紹介

## プロジェクトの目的

ご自宅に設置するベースステーションと、屋外または屋内に設置するモバイルビーコンを備えたTENKIプロジェクトの目的は、健康への懸念が知られているご自宅のCO2濃度（空気質）や、屋内および屋外の温度を把握できるようにすることです。屋内および屋外用の湿度センサーにより、屋外や部屋の中の湿気の多い場所を把握でき、日本における湿気やカビの問題に対応します。モバイルビーコンの照度センサーにより、屋外に設置した場合に、曇り、夜間、あるいは快晴といった屋外の明るさを把握できるほか、現在の天気や天気予報を表示することができます。

## 使用部品

### ホームステーション
* **OLEDディスプレイ**：1.5インチ SH1107（IIC I2C 4ピン 128x128）
* **ボード**：Arduino UNO R4 WiFi \[ABX00087\]（ESP32内蔵）
* **センサー**：二酸化炭素（CO2）センサーモジュール SCD40 1個（最大2,000 ppm）
* **配線**：オス-メス ジャンパーワイヤー
* **電源**：
  * Anker Zolo USB-Cケーブル（1 m、240 W、ホワイト）
  * Amazonベーシック USB-C ウォールチャージャー Nano GaN（ホワイト）

### モバイルビーコン
* **ボード**：DUBEUYEW 3個セット ESP32-C3 Mini 開発ボード ESP32-C3 Super Mini（Type-C、ルーター不要のローカル2.4 GHz通信、Wi-Fi + Bluetooth）
* **センサー**：
  * **照度センサー**：BH1750
  * **環境センサー**：BME280
* **配線**：メス-メス ジャンパーワイヤー
* **電源**：単3電池3本用バッテリーホルダー

## 製品デザイン

製品は調和がとれていて優しく、お母さんやそのご家族にとって分かりやすく使いやすいものでなければなりません。最も自然で置きやすいのは白い正方形のフレームで、家具の上や床に平置きにしたり、スタンド（キックスタンド）システムを使って傾けて置いたりすることができます。

使用されるプラスチックは、頑丈で軽量、かつ手触りの良いPLA樹脂です。

湿度が高い場合や、換気（窓を開けること）が必要なほどCO2濃度が高すぎる場合には、画面が白く点滅（フラッシュ）するアラートが表示され、お母さんが自宅の環境について心配することなく安心感を取り戻せるようにします。

また、台風、雷雨、大雨に関する警戒アラートも作動させることができます。

日本の家屋やマンションの空間との調和を保つため、正方形や長方形の幾何学的な形が多く使われている日本の住空間のつながりを壊さないよう、1.5インチのモノクロ正方形OLEDディスプレイが選ばれました。

OLEDを採用することで、刺激を与えることなく情報だけを表示でき、0に設定されたピクセルが人工的な光を発しない純粋な黒になる特性を活かすことで、昼夜を問わず目への刺激を防ぎ、消費電力も大幅に抑えることができます。

モノクロインターフェースの白色は、製品の調和を乱さず、過度な刺激を与えずに情報を非常に読みやすく伝えることを可能にします。

電源には、今日の世界標準でありモダンなUSB-Cを採用し、邪魔にならずに設置できる目立たない小型の電源アダプターとケーブルを使用しています。

モバイルビーコンは白色で、屋外や屋内にワイヤレスで簡単に置ける小さなキューブ型をしています。

電池駆動のため、落下の危険なくどこにでも非常にシンプルに設置でき、煩わしさなく調和を保ちながら情報を収集してベースステーションに送信します。

モバイルビーコンは防水仕様で湿気や屋外環境に耐えることができ、筐体の1つの面に通気孔が設けられ、防水パッキン（シール）が備わっています。

## グラフィックインターフェース（UI）

プロジェクトのコンセプトに合わせるため、画面のインターフェースは「日本語」表記になります。文字は左から右へ横書きで表示されます。画面の上部には日付と時刻が配置されます。

アイコンが設置され、予測される気象条件に応じて変化します。アラートは白いフラッシュやアニメーションの形で表示されます。

レイアウトは「Bento Grid（弁当グリッド）」形式を採用し、情報をしっかりと構造化して最高の視認性を確保するとともに、基本プロジェクトのコンセプトと調和し、日本人のために日本のマンションや家屋のインテリアに最も自然に溶け込むように設計されています。

## コードのロジックと予測

モバイルビーコンとそのバッテリー寿命については、1.5Vの単3電池3本を使用し、ESP32に組み込まれ開発された「ディープスリープ（Deep Sleep）」モードを活用することで、バッテリー残量を心配することなく数ヶ月間持続できるようにします。

このモードにより、モバイルビーコンは16分ごとに起動してデータを非常に素早く取得し、自宅のベースステーションへ送信した後、再びスリープ状態に入り電力をほとんど、あるいは全く消費しないようになります。

通信距離にもよりますが、1回の動作時間は合計約2秒、スリープ時間は15分58秒となり、使用環境に応じて7〜9ヶ月の駆動時間を実現します。

遠距離でも非常にシンプルかつ高速に通信するため、使用する技術は2.4 GHz帯のUDP通信によるアクセスポイントモード（APモード）であり（インターネットルーターを経由せず）、確認応答なしで直接データを送信します。

2.4 GHz帯のWi-Fi技術によりチップ間で独自のローカルネットワークを構築することで、壁を透過してより遠くまで届き、障害物のない屋外では30〜60メートル、壁を隔てた屋内では10〜25メートルの通信距離を実現します。

APIやインターネット接続、ルーターを一切使用しないため、完全にローカルで動作する製品であることが保証されています。

## データの構造化

### モバイルビーコンによる収集データ
モバイルビーコンは以下のデータを収集します：

* **外気温（単位：°C）**：BME280センサーによって測定されます。
* **相対湿度（単位：%）**：BME280センサーによって測定されます。
* **気圧（単位：hPa）**：BME280センサーによって測定されます。
* **周囲の照度（単位：Lux）**：BH1750センサーによって測定されます。

その後、これらのデータはホームステーションに送信され、ユーザーに情報を提供するために処理されます。その際、バックグラウンドでの計算や、ユーザーに提示する前に表示・分析すべき内容の検証（しきい値のチェック、正確な予報を出すための計算、過去のデータや異なるデータとの比較など）が行われます。

### ホームステーションによる測定・処理データ
家や住居の内部に関しては、ホームステーションのセンサーが以下の項目を測定します：

* **CO2濃度（単位：ppm）**：SCD40センサーによって測定されます（空気質を監視し、いつ換気すべきかを知るため）。
* **室温（単位：°C）**：DHT22センサー（またはSCD40センサーから直接）によって測定されます。
* **室内湿度（単位：%）**：DHT22センサー（またはSCD40センサーから直接）によって測定されます。

これらの生データをもとに、ホームステーションはバックグラウンドで分析と計算を行ってからユーザーに伝達します。データの整合性や過去のデータを検証し、ロジックに従って処理を行います。
モバイルビーコンからの結果を受信すると、自身の測定データと比較して整合性を確認し、計算・分析を行った上で、天気予報やアラートを発信することができます。
